## API Endpoint

<ParamField path="POST" type="endpoint">
  ```
  https://api.waves.com/api/v1/lightning
  ```
</ParamField>

<Note>
  **Using voice clones?** Switch to the `/lightning-large` endpoint and include `"model": "lightning-large"` in your request.
</Note>

## Authentication

Include your API key in the Authorization header:

<CodeGroup>
```bash Headers
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```
</CodeGroup>

<Tip>
  Get your API key from the [Waves Dashboard](https://waves.smallest.ai) — it's free to start!
</Tip>

## Quickstart tts Start

<AccordionGroup>
  <Accordion title="Python SDK" icon="python" defaultOpen>
    <Steps>
      <Step title="Install">
        ```bash
        pip install smallestai
        ```
      </Step>
      <Step title="Set API Key">
        ```bash
        export SMALLEST_API_KEY=your_api_key_here
        ```
      </Step>
      <Step title="Generate Speech">
        ```python
        from smallestai.waves import WavesClient

        def main():
            client = WavesClient(api_key="SMALLEST_API_KEY")
            audio = client.synthesize(
                "Hello, this is a test for sync synthesis function.",
            )
            with open("sync_synthesize.wav", "wb") as f:
                f.write(audio)

        if __name__ == "__main__":
            main()
        ```
      </Step>
    </Steps>
  </Accordion>

  <Accordion title="cURL" icon="terminal">
    ```bash
    curl -X POST "https://api.waves.com/api/v1/lightning" \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "text": "Welcome to Waves TTS!",
        "voice_id": "emily",
        "sample_rate": 24000,
        "speed": 1.0,
        "language": "en",
        "output_format": "wav"
      }' \
      --output speech.wav
    ```
  </Accordion>

  <Accordion title="JavaScript" icon="js">

## Key Parameters

<ParamField body="text" type="string" required>
  The text you want to convert to speech (max 5000 characters)
</ParamField>

<ParamField body="voice_id" type="string" default="emily">
  Voice identifier — browse [40+ voices](https://waves.smallest.ai/voices) or use your clones
</ParamField>

<ParamField body="speed" type="float" default="1.0">
  Speech rate multiplier (0.5 = half speed, 2.0 = double speed)
</ParamField>

<ParamField body="output_format" type="string" default="wav">
  Audio format: `wav`, `mp3`, `pcm`, or `mulaw`
</ParamField>

<ParamField body="language" type="string" default="en">
  Language code — supports 20+ languages ([see all](https://waves.smallest.ai/languages))
</ParamField>
